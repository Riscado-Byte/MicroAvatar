# MicroAvatar

## A simple avatar generator in python

![demo](/Assets/icon)

## Usage

```
python3 main.py (args)
```

## Options

| Option | or | Description |
|--------|----|-------------|
| -c     | --count | Specifies the amount of avatars |
| -b     | --background | Adds background |
